# Toluwanimi Odunewu

Computational pharmacologist. BSc Pharmacology, Therapeutics and Toxicology, University of Lagos.

I work on machine learning for drug discovery, and mostly on one question inside it: when a
model's output stops being trustworthy, and whether you can tell before it fails rather than
after. That covers applicability domains, benchmark validity, and failure analysis of my own
systems.

### Selected work

- **[lead-optimizer-paper](https://github.com/Nimieeee/lead-optimizer-paper)**
  A vision-language agentic pipeline for lead optimization, with a deterministic chemistry gate
  around every language-model stage. Single-author preprint:
  [10.26434/chemrxiv.15004729](https://doi.org/10.26434/chemrxiv.15004729/v1). Its central
  result is a negative one: recovery of documented molecular transformations was 53.3%
  (95% CI 36.1 to 69.8) on a curated benchmark and 15.5% (95% CI 14.0 to 17.2) on an unbiased
  2,000-pair sample.

- **[schrodinger-mcp](https://github.com/Nimieeee/schrodinger-mcp)**
  A Model Context Protocol server exposing the Schrodinger Suite to an AI agent end to end:
  PDB retrieval through ligand preparation, Glide SP and XP, QikProp, Prime MM-GBSA, SiteMap
  and Jaguar, with asynchronous job orchestration and a regression test suite.

- **[chemberta-vs-rf-data-efficiency](https://github.com/Nimieeee/chemberta-vs-rf-data-efficiency)**
  Where a fine-tuned ChemBERTa starts to beat random forests on ECFP4 fingerprints, measured
  across training-set sizes on four endpoints. Includes a documented bug from a first attempt
  that was caught before release rather than removed.

- **[pubmed-nlp-search](https://github.com/Nimieeee/pubmed-nlp-search)**
  A PubMed NLP pipeline with semantic and relation search.
